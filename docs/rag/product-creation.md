# Как появляется товар в системе

На данный момент предусмотрена следующая схема добавления артикула в систему.

### 1. Создание товара на Wildberries

Сначала товар необходимо создать на маркетплейсе **Wildberries**.

### 2. Синхронизация с системой

После создания товара он автоматически загружается из Wildberries в нашу систему.

> **Важно:** обновление списка товаров происходит автоматически **раз в 40 минут**. Поэтому сразу после создания товара он может быть еще недоступен в системе.

### 3. Получение данных в Master Data

После того как товар синхронизировался с Wildberries, необходимо открыть таблицу **Master Data** и запустить скрипт:

**Меню → Товары → Получить данные**

Если товар уже успел синхронизироваться с маркетплейсом, после выполнения скрипта он появится в списке товаров.

### Итоговая схема

**Wildberries → синхронизация (до 40 минут) → Master Data → Меню → Товары → Получить данные → товар появляется в списке**
