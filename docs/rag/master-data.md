# Для чего служат листы в Master Data

В таблице **Master Data** используется несколько листов, каждый из которых содержит определенный тип информации о товарах, поставщиках и контрагентах.

## 1. Товары

На листе **«Товары»** отображается основная информация о товаре:

* артикул;
* наименование;
* фотография;
* описание;
* категория.

Этот лист содержит общую информацию, которая относится непосредственно к товару.

## 2. Поставщики — SKU

Лист **«Поставщики — SKU»** содержит информацию о том, **какой поставщик производит какой артикул**, а также условия и характеристики производства.

Для каждого артикула могут быть указаны:

* поставщик;
* закупочная стоимость;
* минимальное количество для заказа;
* габариты товара;
* срок производства;
* срок сборки;
* количество штук в коробке;
* и другие параметры.

> **Важно:** один и тот же артикул могут производить **несколько разных поставщиков**. Поэтому для одного артикула в таблице может быть несколько записей.

## 3. Логистика — SKU

Лист **«Логистика — SKU»** содержит логистическую информацию по товарам.

Здесь указываются:

* срок доставки;
* срок приемки;
* срок консолидации груза;
* используемый вид транспорта;
* код ТН ВЭД;
* тип расчета;
* тип упаковки;
* и другие логистические параметры.

## 4. Поставщики

Лист **«Поставщики»** содержит перечень поставщиков и основную информацию о них.

В частности, здесь могут быть указаны:

* наименование поставщика;
* контактные данные;
* юридическое наименование;
* условия оплаты;
* возможность хранения товара на складе поставщика;
* и другие сведения о поставщике.

## 5. Контрагенты

Лист **«Контрагенты»** содержит информацию о контрагентах и по своей структуре похож на лист **«Поставщики»**.

Здесь указываются:

* наименование;
* юридические данные;
* условия оплаты;
* и другие основные сведения о контрагенте.

## Редактирование данных

Информация, которую пользователь может редактировать вручную, **выделена желтым цветом**.

После внесения изменений необходимо запустить скрипт:

**Меню → Изменить данные**

Запуск этого скрипта необходим для того, чтобы внесенные изменения были переданы и сохранены в системе.

> **Важно:** не следует изменять данные в ячейках, которые не выделены желтым цветом, если это не предусмотрено инструкцией.
