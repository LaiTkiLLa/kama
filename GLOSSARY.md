# Kama

Домен операций с маркетплейсами: товары, листинги, размеры и снимки остатков (WB / Ozon / Yandex).

## Язык

**Товар (Item)**:
Продукт без привязки к маркетплейсу; один на артикул (кроме расчётных товаров).
_Не использовать_: Product (двусмысленно), SKU

**Листинг (Listing)**:
Присутствие товара в одном кабинете маркетплейса (`marketplace_items`).
_Не использовать_: «строка marketplace item» (деталь реализации), карточка (только UI)

**Размер МП (Marketplace Size)**:
Вариация размера у листинга на конкретном маркетплейсе (`marketplace_item_sizes`; напр. WB `chrtID`).
_Не использовать_: размер из характеристик товара, один только `techSize`, SKU

**Снимок остатков (листинг)**:
Дневное количество по листингу на складе (`stocks`).
_Не использовать_: «сток», «баланс» без уточнения

**Снимок остатков (размер)**:
Дневное количество по размеру МП на складе (`stocks_v2`).
_Не использовать_: «строка stocks_v2» в доменном разговоре
